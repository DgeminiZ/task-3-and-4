Единый артефакт для двух тем ВКР:

1. «Исследование методов ускорения рендеринга WebGL графики для формирования рекомендаций для разработчиков».
2. «Исследование производительности и пользовательского опыта прогрессивных веб-приложений (PWA) в условиях ограниченного доступа к сети».

## Коротко о стенде

`research-stand` — воспроизводимый экспериментальный стенд: PWA с WebGL-сценой (SUT),
браузерный раннер на Playwright, оркестратор прогонов и скрипт статистического анализа.
Одна и та же конструкция покрывает обе темы: фактор `render` относится к методам ускорения
рендеринга, факторы `transport` и `mode` — к работе PWA при ограниченной сети.

## Как воспроизвести

```bash
cd research-stand
make up
make smoke
make experiment
make analyze
```

Windows:

```powershell
cd research-stand
.\run.ps1 up
.\run.ps1 smoke
.\run.ps1 experiment
.\run.ps1 analyze
```

Подробности — в `research-stand/README.md`.

## Фактическое выполнение

Основная кампания (115 прогонов, из них 105 валидных) выполнена в локальном режиме:
на машине не был установлен Docker. Использовались тот же раннер и тот же Chromium
(153.0.8010.12), окружение: Windows 11, Intel Core i5-1335U, 12 потоков, 15,6 ГБ RAM,
Intel UHD Graphics (ANGLE D3D11). Контейнерная конфигурация входит в артефакт и
запускается командами выше; расхождение локального и контейнерного режимов отмечено в
ПР4 как ограничение.

## Ключевые результаты

- `InstancedMesh` против отдельных мешей при 35 000 объектов: медиана FPS 49,21 против
  11,65 (рост на 322 %, p < 0,001, δ Клиффа = 1,00).
- LOD без батчинга: −17 % FPS; гипотеза о положительном эффекте отклонена.
- Service worker при повторном визите в сети 3G: загрузка −78,7 %, время до первого
  кадра −87,3 %, трафик −100 % (p < 0,001).
- Офлайн-доступность: 10/10 успешных загрузок с service worker и 0/10 без него.
- A/A-тест: p = 0,84, δ = −0,12; шум стенда 5,7 %, минимальный обнаруживаемый эффект 16 %.
